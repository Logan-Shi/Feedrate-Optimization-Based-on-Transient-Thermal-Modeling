# Example data

`heat_flux_fits/` contains the fitted Gaussian heat-flux model for each case:
`GeoA`, `GeoB`, `GeoC_p45`, `GeoC_0`, and `GeoC_m45`. GeoA is the doubly curved
case, GeoB is a ruled surface, and GeoC_p45, GeoC_0, and GeoC_m45 correspond to Boat Hull -45, 0, and 45 degree orientations. 

`model/sample/` contains the STL meshes for GeoA, GeoB, and GeoC.
